# Photo slots

Add your own photos to this folder using these exact filenames. The profile will show a styled placeholder until each file is present.

- `portrait.jpg` — professional portrait
- `friesland-visit.jpg` — circular-economy or Friesland programme visit
- `professional-moment.jpg` — professional learning, speaking, or a finance-transformation moment

Use JPG or PNG photos, crop to landscape for the two field-note slots, and avoid images containing confidential workplace, client or financial information. Upload the image files in this folder to GitHub to make them appear on the site.
